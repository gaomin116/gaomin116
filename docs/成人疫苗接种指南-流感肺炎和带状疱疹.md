# 成人疫苗接种指南：流感、肺炎和带状疱疹

为了做好院后延伸服务，帮助成人患者了解常见疫苗接种知识，医院保健科整理了这篇健康教育内容。疫苗接种是预防感染性疾病及其重症并发症的重要措施，但是否适合接种、何时接种、接种哪一种疫苗，应结合年龄、基础疾病、过敏史、免疫状态和当地疫苗供应情况，由预防接种门诊或医生综合评估。

## 一、为什么成人也需要接种疫苗

很多人认为疫苗主要是儿童接种，其实成年人尤其是老年人、慢性病患者、免疫功能低下者，感染流感、肺炎球菌性疾病和带状疱疹后，更容易出现住院、并发症或生活质量下降。规范接种疫苗可以降低感染、重症和相关并发症风险。

成人接种疫苗前，建议先梳理以下信息：

1. **年龄和基础疾病**：如高血压、糖尿病、慢阻肺、冠心病、慢性肾病等。
2. **既往接种史**：是否接种过同类疫苗，接种时间和剂次。
3. **过敏史和不良反应史**：尤其是对疫苗成分严重过敏。
4. **当前健康状态**：发热、急性感染、疾病急性发作期通常需暂缓接种。
5. **特殊情况**：妊娠、备孕、免疫抑制治疗、肿瘤治疗等应提前咨询医生。

## 二、流感疫苗：建议每年接种

流感病毒容易变异，流感疫苗成分会根据流行情况更新，因此建议每年接种。接种后通常需要约2周产生较好保护，最好在当地流感流行季前完成接种；如果错过最佳时间，整个流行季仍可接种。

**优先建议接种人群：**

- 60岁及以上老年人。
- 慢性病患者，如慢性呼吸系统疾病、心血管疾病、糖尿病、慢性肾病等。
- 医务人员、养老机构和长期护理机构工作人员。
- 孕妇、婴幼儿照护者和家庭成员。
- 经常出入人群密集场所的人群。

**接种提醒：**

- 成人通常每年接种1剂。
- 接种后仍可能感染流感，但可降低重症和并发症风险。
- 对鸡蛋过敏或有严重过敏史者，应主动告知接种医生。
- 流感疫苗不能治疗已经发生的感冒或流感。

## 三、肺炎球菌疫苗：老年人和慢病患者要重视

肺炎球菌可引起肺炎、中耳炎、脑膜炎、菌血症等疾病。老年人、慢性病患者和免疫功能低下者感染后更容易发展为重症。

**建议重点咨询接种的人群：**

- 60岁或65岁及以上老年人，具体以当地接种政策和疫苗说明书为准。
- 慢性心肺疾病、糖尿病、慢性肝肾疾病患者。
- 脾功能不全或脾切除者。
- 免疫功能低下者，如长期使用免疫抑制剂、恶性肿瘤治疗期间等。
- 长期吸烟者、长期照护机构居住者。

**接种提醒：**

- 肺炎球菌疫苗有不同类型，接种程序可能不同。
- 既往接种过的人，应带上接种记录，由接种门诊判断是否需要补种或加强。
- 接种肺炎球菌疫苗不能预防所有肺炎，但可降低肺炎球菌相关疾病风险。

## 四、带状疱疹疫苗：中老年人应主动了解

带状疱疹俗称“缠腰龙”，由潜伏在体内的水痘-带状疱疹病毒再激活引起。年龄增长、疲劳、免疫功能下降时风险增加。部分患者皮疹消退后仍会长期神经痛，影响睡眠和生活质量。

**建议重点咨询接种的人群：**

- 50岁及以上人群。
- 曾经患过水痘或带状疱疹者，也可咨询是否适合接种。
- 慢性病稳定期人群。
- 担心带状疱疹后神经痛、生活质量受影响的人群。

**接种提醒：**

- 带状疱疹疫苗有不同类型，剂次和间隔不同，应按说明书和接种门诊建议完成。
- 正在发作带状疱疹时不建议立即接种，应待急性期恢复后咨询医生。
- 免疫功能低下、正在接受免疫抑制治疗者，必须先咨询医生。

## 五、接种前后注意事项

1. 接种当天如有发热、急性感染、慢性病急性发作，应主动告知。
2. 接种后按要求留观，一般为30分钟。
3. 接种部位短暂疼痛、红肿，或轻微乏力、低热，多数可自行缓解。
4. 若出现呼吸困难、全身皮疹、面唇肿胀、持续高热等，应及时就医。
5. 接种后仍需保持戴口罩、手卫生、通风、规律作息等健康习惯。

## 六、适合自己的接种计划怎么定

建议携带身份证、既往接种记录、近期病历或用药清单，到社区卫生服务中心、预防接种门诊或医院相关门诊咨询。对老年人和慢性病患者来说，可在病情稳定期，将流感、肺炎球菌和带状疱疹疫苗纳入年度健康管理计划。

疫苗接种不是“一针解决所有问题”，而是健康管理的一部分。规律接种、慢病控制、合理营养、适量运动和良好睡眠结合起来，才能更好地降低感染和重症风险。

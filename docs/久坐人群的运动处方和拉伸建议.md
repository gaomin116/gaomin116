# 久坐人群的运动处方和拉伸建议

为了做好院后延伸服务，帮助久坐人群改善身体状态，医院保健科整理了这篇健康教育内容。久坐不是简单的“坐得久”，而是长时间低能量消耗的静态行为。长期久坐会增加颈肩腰背疼痛、肥胖、血糖血脂异常、心血管疾病和睡眠问题风险。改变久坐，关键是“少坐、多动、循序渐进”。

## 一、哪些人属于久坐高风险人群

以下情况提示需要主动调整：

- 每天坐着工作或学习超过6小时。
- 连续坐着超过1小时很少起身。
- 经常颈肩酸痛、腰背僵硬、下肢发胀。
- 下班后仍长时间看手机、电脑或电视。
- 运动少，同时有体重增加、血糖血脂异常或脂肪肝。
- 长期开车、伏案办公、线上工作、备考学习人群。

## 二、久坐人群的基本运动目标

对成年人来说，建议每周累计进行150到300分钟中等强度有氧运动，或75到150分钟较高强度有氧运动，并每周至少2天进行肌肉力量训练。久坐人群刚开始不必追求高强度，先把“坐太久”打断，再逐步建立运动习惯。

**中等强度的简单判断：**

- 运动时心跳和呼吸加快。
- 可以说话，但不能轻松唱歌。
- 运动后微微出汗，身体有发热感。

## 三、办公室“打断久坐”方案

建议每坐30到60分钟，起身活动2到5分钟。

**可以选择：**

- 原地踏步或走廊快走。
- 站立接电话。
- 做10到15次提踵。
- 做8到12次靠墙俯卧撑。
- 上下楼梯1到2层。
- 伸展颈肩、胸背和髋部。

如果工作条件允许，可使用升降桌，坐站交替办公。但站立也不能完全替代运动，仍需规律活动。

## 四、每周运动处方示例

### 初级方案

适合平时几乎不运动、体能较弱的人群。

- 快走：每次20分钟，每周5天。
- 拉伸：每天5到10分钟。
- 抗阻训练：每周2次，每次15分钟。

### 进阶方案

适合已经能规律快走或慢跑的人群。

- 有氧运动：每次30到45分钟，每周4到5天。
- 抗阻训练：每周2到3次。
- 柔韧和平衡训练：每周2到3次。

### 忙碌人群碎片化方案

适合工作时间不固定的人群。

- 上午快走10分钟。
- 午后楼梯或原地踏步10分钟。
- 晚饭后步行20分钟。
- 睡前做全身拉伸8分钟。

碎片化运动同样有价值，关键是坚持和累计。

## 五、力量训练怎么做

力量训练可以改善肌肉力量、姿势稳定和代谢水平。建议从自身体重训练开始。

**推荐动作：**

- 深蹲或坐站训练。
- 靠墙俯卧撑。
- 弹力带划船。
- 臀桥。
- 平板支撑或死虫式。
- 提踵训练。

每个动作8到12次，做1到3组。动作过程中保持呼吸，不要憋气。高血压、心脏病、关节疾病患者应先咨询医生或康复治疗师。

## 六、常用拉伸建议

拉伸应缓慢、稳定、无明显疼痛，每个动作保持15到30秒，重复2到3次。

### 1. 颈部放松

坐姿或站姿，肩膀放松，头轻轻向一侧倾斜，感受颈侧拉伸。不要用力甩头或快速转头。

### 2. 胸肌拉伸

站在门框旁，前臂扶住门框，身体轻轻向前，感受胸前打开。适合长期含胸伏案人群。

### 3. 肩胛放松

双手向前交叉，背部微微拱起，感受上背部拉伸。可缓解肩胛区紧张。

### 4. 髋屈肌拉伸

弓步站立，后侧腿髋部向前下方轻推，感受大腿前侧和髋前方拉伸。适合久坐后髋部紧的人群。

### 5. 腘绳肌拉伸

一侧腿向前伸直，脚尖回勾，身体从髋部轻轻前倾，感受大腿后侧拉伸。

### 6. 小腿拉伸

面对墙站立，一脚在前一脚在后，后腿伸直、脚跟踩地，身体向墙靠近，感受小腿后侧拉伸。

## 七、出现这些情况应暂停并就医

- 运动中胸痛、胸闷、明显气短。
- 头晕、黑矇、心悸明显。
- 关节疼痛加重或肿胀。
- 腰腿痛伴麻木、无力、大小便异常。
- 运动后不适持续不能缓解。

久坐人群最重要的改变，是把“长时间不动”变成“经常小动、规律运动”。不用等到有整块时间才开始，每一次起身、每一次步行、每一次拉伸，都是对健康的投资。

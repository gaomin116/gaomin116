# 常见癌症筛查项目和适宜人群

为了做好院后延伸服务，帮助患者正确理解癌症筛查，医院保健科整理了这篇健康教育内容。癌症筛查不是“项目越多越好”，也不是抽几项肿瘤标志物就能发现所有癌症。科学筛查应根据年龄、性别、家族史、生活方式、既往疾病和地区高发特点，选择适合自己的项目。

## 一、癌症筛查和普通体检有什么不同

普通体检主要了解整体健康状况，如血压、血糖、血脂、肝肾功能等。癌症筛查是针对某些癌种，在无症状或症状很轻时，寻找早期癌或癌前病变。

**需要注意：**

- 不是所有癌症都有适合大众筛查的方法。
- 筛查有假阳性和假阴性，异常结果需要进一步检查。
- 肿瘤标志物升高不等于癌症，正常也不能排除癌症。
- 高危人群更应进行有针对性的筛查。

## 二、肺癌筛查

**适宜人群：**

- 年龄较大且有长期吸烟史者。
- 已戒烟但曾长期吸烟者。
- 长期二手烟、职业粉尘、石棉、氡等暴露者。
- 有慢性肺病或肺癌家族史者。

**常用筛查方法：**

- 低剂量螺旋CT。

**提醒：**

普通胸片发现早期肺癌能力有限。肺结节不等于肺癌，但需要根据大小、形态、密度和变化定期随访。

## 三、结直肠癌筛查

**适宜人群：**

- 40岁或45岁以上人群，可根据地区和指南建议开始筛查。
- 有结直肠癌或肠息肉家族史者。
- 既往有肠息肉、炎症性肠病者。
- 长期便血、排便习惯改变、原因不明贫血者。

**常用筛查方法：**

- 粪便隐血或粪便免疫化学检测。
- 结肠镜检查。

**提醒：**

结肠镜不仅能发现癌症，也能发现并处理部分癌前病变。出现便血不要简单认为是痔疮，应及时评估。

## 四、胃癌筛查

**适宜人群：**

- 胃癌高发地区人群。
- 有胃癌家族史者。
- 幽门螺杆菌感染者。
- 慢性萎缩性胃炎、胃溃疡、胃息肉、胃黏膜肠化生或异型增生者。
- 长期高盐、腌制、烟熏饮食或吸烟饮酒者。

**常用筛查方法：**

- 胃镜检查。
- 幽门螺杆菌检测。

**提醒：**

胃镜是发现早期胃癌和癌前病变的重要方法。长期胃痛、黑便、消瘦、贫血等症状应及时就医。

## 五、肝癌筛查

**适宜人群：**

- 乙肝或丙肝感染者。
- 肝硬化患者。
- 长期大量饮酒者。
- 非酒精性脂肪性肝病合并明显肝纤维化者。
- 有肝癌家族史者。

**常用筛查方法：**

- 肝脏超声。
- 甲胎蛋白。

**提醒：**

肝癌高危人群通常需要定期筛查，不能只等肝区疼痛再检查。乙肝、丙肝患者应规范抗病毒和随访。

## 六、乳腺癌筛查

**适宜人群：**

- 40岁及以上女性。
- 有乳腺癌或卵巢癌家族史者。
- 既往乳腺不典型增生或胸部放疗史者。
- 月经初潮早、绝经晚、未育或晚育等风险因素较多者。

**常用筛查方法：**

- 乳腺X线摄影。
- 乳腺超声。
- 高危人群必要时加做乳腺磁共振。

**提醒：**

乳腺自检不能替代影像筛查。发现乳房肿块、乳头溢液、皮肤凹陷或腋窝肿块，应及时就诊。

## 七、宫颈癌筛查

**适宜人群：**

- 有性生活史的适龄女性。
- HPV感染风险较高者。
- 既往宫颈病变者。

**常用筛查方法：**

- 高危型HPV检测。
- 宫颈细胞学检查。

**提醒：**

宫颈癌是可以通过疫苗接种和筛查共同预防的癌症。接种HPV疫苗后仍需按年龄和医生建议进行筛查。

## 八、食管癌筛查

**适宜人群：**

- 食管癌高发地区人群。
- 长期吸烟饮酒者。
- 长期进食过烫、腌制、霉变食物者。
- 有食管癌家族史或上消化道症状者。

**常用筛查方法：**

- 内镜检查。

**提醒：**

吞咽困难、胸骨后不适、进食哽噎感持续存在，应及时就医。

## 九、如何制定个人筛查计划

1. 先向医生说明年龄、性别、家族史和既往病史。
2. 带上历年体检报告和影像资料。
3. 不盲目做全套肿瘤标志物。
4. 高危人群按医生建议定期复查。
5. 筛查异常后按流程进一步检查，不要过度恐慌或拖延。

癌症筛查的目标是早发现、早诊断、早治疗。适合自己的筛查，比“项目越贵越多”更重要。

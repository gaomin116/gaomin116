# 戒烟限酒对健康的长期好处

为了做好院后延伸服务，帮助患者了解生活方式改变带来的长期收益，医院保健科整理了这篇健康教育内容。吸烟和过量饮酒是多种慢性病、恶性肿瘤和心脑血管疾病的重要危险因素。戒烟越早越好，任何年龄开始戒烟都能获益；饮酒应尽量少饮，不饮酒者不建议为了健康而开始饮酒。

## 一、为什么要戒烟

烟草烟雾中含有多种有害物质，可损伤呼吸道、血管内皮和全身多个器官。吸烟不仅影响本人，也会让家人暴露于二手烟、三手烟风险中。

**吸烟相关风险包括：**

- 慢性支气管炎、慢阻肺、肺功能下降。
- 冠心病、脑卒中、外周血管疾病。
- 肺癌及多种恶性肿瘤。
- 糖尿病控制变差、伤口愈合变慢。
- 男性生殖健康受影响，女性妊娠风险增加。
- 家庭成员尤其是儿童、孕妇和老人受到二手烟危害。

## 二、戒烟后身体会发生什么变化

戒烟的好处不是很多年后才出现，而是从停止吸烟后逐渐开始。

**可能获得的长期收益：**

- 咳嗽、咳痰、气短逐渐改善。
- 心血管事件风险下降。
- 肺功能下降速度减慢。
- 多种癌症风险降低。
- 口腔异味、牙周问题和皮肤状态改善。
- 家庭二手烟暴露减少。
- 运动耐力和生活质量提高。

已经患有高血压、糖尿病、冠心病、慢阻肺或肿瘤的人，戒烟同样重要，可帮助降低复发、进展和并发症风险。

## 三、戒烟为什么容易失败

戒烟困难并不只是“意志力不够”。烟草依赖与尼古丁成瘾、行为习惯和情绪压力有关。

常见诱因包括：

- 饭后、饮酒、熬夜时想吸烟。
- 工作压力大、情绪烦躁时想吸烟。
- 周围朋友递烟或社交场景影响。
- 担心戒烟后发胖。
- 出现戒断症状，如烦躁、注意力下降、睡眠差。

认识诱因，提前准备替代方案，有助于提高成功率。

## 四、提高戒烟成功率的方法

1. **设定戒烟日**：选择一个明确日期开始完全停止吸烟。
2. **清理环境**：扔掉烟、打火机、烟灰缸。
3. **告知家人朋友**：获得支持，减少递烟和劝烟。
4. **避开诱因**：饭后立即刷牙、散步或喝水。
5. **应对烟瘾**：深呼吸、喝水、咀嚼无糖口香糖、短暂离开诱发场景。
6. **寻求专业帮助**：戒烟门诊可提供行为干预和必要药物治疗。

如果复吸，不代表失败。应分析复吸原因，重新制定计划。

## 五、为什么要限酒

酒精不是保健品。过量饮酒会增加肝病、消化道疾病、高血压、心律失常、脑卒中、痛风、意外伤害和部分癌症风险。饮酒还可能影响睡眠质量、血糖控制和用药安全。

**尤其应避免饮酒的人群：**

- 孕妇、备孕人群、未成年人。
- 肝病、胰腺疾病、痛风患者。
- 高血压控制不佳、心律失常或脑卒中病史者。
- 正在服用头孢类、硝咪唑类、镇静催眠药、抗凝药等药物者。
- 有酒精依赖或饮酒失控史者。

## 六、如何做到少喝或不喝

1. 不把饮酒作为助眠、解压方式。
2. 聚餐前先说明自己少喝或不喝。
3. 用无糖茶水、苏打水等替代酒精饮品。
4. 避免空腹饮酒和快速饮酒。
5. 不劝酒、不拼酒，不把饮酒量当作社交能力。
6. 若出现无法控制饮酒、停酒后手抖出汗、焦虑失眠，应及时就医。

## 七、戒烟限酒与慢病管理

对高血压患者，戒烟限酒有助于血压控制和降低心脑血管风险。对糖尿病患者，可减少血糖波动和并发症风险。对血脂异常、脂肪肝、痛风患者，限制酒精摄入尤其重要。对肿瘤康复患者，戒烟限酒也是降低复发和第二原发癌风险的重要措施之一。

## 八、给患者的提醒

戒烟限酒不是一句口号，而是可以逐步执行的健康计划。建议从“今天少一支烟、少一次酒局”开始，逐步过渡到完全戒烟和尽量不饮酒。需要帮助时，请主动咨询戒烟门诊、全科门诊、呼吸科、心内科、消化科或精神心理相关门诊。

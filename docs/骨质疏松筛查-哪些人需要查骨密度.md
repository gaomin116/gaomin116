# 骨质疏松筛查：哪些人需要查骨密度

为了做好院后延伸服务，帮助患者尽早发现骨质疏松风险，医院保健科整理了这篇健康教育内容。骨质疏松早期常没有明显症状，很多人是在摔倒骨折后才发现。骨密度检查可以帮助评估骨量和骨折风险，是骨质疏松筛查和诊断的重要工具。

## 一、骨质疏松为什么容易被忽视

骨质疏松是一种骨量下降、骨微结构受损、骨脆性增加的疾病。它不像感冒发烧那样容易被察觉，早期可能没有疼痛。等出现身高变矮、驼背、腰背痛或脆性骨折时，骨量丢失往往已经比较明显。

**需要警惕的表现：**

- 轻微外力或平地摔倒后骨折。
- 身高较年轻时明显变矮。
- 驼背、腰背痛。
- 老年人反复跌倒。
- 影像检查提示椎体压缩性改变。

## 二、哪些人建议查骨密度

以下人群建议主动咨询医生是否需要骨密度检查：

- 绝经后女性。
- 50岁及以上男性，尤其合并危险因素者。
- 65岁及以上女性、70岁及以上男性。
- 发生过脆性骨折者。
- 父母有髋部骨折史者。
- 长期低体重、营养不良或过度节食者。
- 长期吸烟、过量饮酒、缺乏运动者。
- 长期使用糖皮质激素或影响骨代谢药物者。
- 患有类风湿关节炎、甲状旁腺功能亢进、甲状腺功能异常、慢性肝肾疾病、糖尿病、慢性腹泻等疾病者。
- 乳腺癌、前列腺癌等接受影响性激素治疗的人群。

## 三、骨密度检查是什么

临床常用的骨密度检查是双能X线吸收检测法，简称DXA。它通常测量腰椎和髋部骨密度，辐射剂量较低，检查时间较短。

**检查前提醒：**

- 检查当天穿着尽量避免金属装饰。
- 近期做过造影、核医学检查或含钡检查，应告知医生。
- 妊娠或可能妊娠者，应提前说明。
- 带上既往骨密度报告，便于比较变化。

## 四、报告怎么看

骨密度报告常见指标包括T值和Z值。绝经后女性和50岁及以上男性通常参考T值。一般来说：

- T值≥-1.0：骨量正常。
- -2.5<T值<-1.0：骨量减少。
- T值≤-2.5：提示骨质疏松。

是否需要治疗不能只看一个数字，还要结合年龄、骨折史、跌倒风险、用药史、基础疾病和骨折风险评估结果。

## 五、哪些情况即使骨密度不低也要重视

有些人骨密度没有达到骨质疏松标准，但已经发生低能量骨折，仍提示骨折风险较高。尤其是髋部、椎体、肱骨近端、前臂远端等部位脆性骨折，应及时到骨质疏松门诊、内分泌科、老年医学科、骨科或风湿免疫科评估。

## 六、如何保护骨骼

1. **保证钙和维生素D摄入**：优先通过奶类、豆制品、深绿色蔬菜等获得营养，是否补充钙剂和维生素D应咨询医生。
2. **规律负重运动**：如快走、爬楼、力量训练和平衡训练。
3. **预防跌倒**：改善家中照明，浴室防滑，避免地面杂物。
4. **戒烟限酒**：烟酒都会影响骨健康。
5. **适当晒太阳**：帮助维生素D合成，但注意防晒和避免暴晒。
6. **治疗基础疾病**：如甲状腺、肾脏、风湿免疫疾病等。

## 七、已经诊断骨质疏松怎么办

骨质疏松需要长期管理。医生可能根据风险建议补充钙剂、维生素D或使用抗骨质疏松药物。患者应按医嘱复诊，不要自行停药。治疗期间仍需运动、营养、跌倒预防和生活方式管理配合。

## 八、给患者的提醒

骨密度检查不是老年人才需要。绝经后女性、发生过脆性骨折的人、长期使用激素或有多种危险因素的人，都应主动筛查。早发现、早干预，可以降低骨折风险，保护行动能力和生活质量。
